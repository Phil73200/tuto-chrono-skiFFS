# Guide InfoFIS — Recevoir une FIS dans votre station

Ouvrir `index.html` dans un navigateur pour consulter le guide. Aucune installation ni connexion n’est nécessaire pour lire le contenu et agrandir les captures. Les liens externes nécessitent Internet.

## Dépôt sur GitHub

Copier le dossier entier dans le dépôt InfoFIS, par exemple sous `tutoriels/recevoir-une-fis/`. Conserver les chemins relatifs : `index.html`, `style.css`, `guide.js`, `images/` et `tutoriel-original.pdf`. Pointer ensuite le menu du site vers ce dossier ou son fichier `index.html`.

Ce livrable est autonome, sans bibliothèque, police distante ni suivi d’audience. Il n’a pas été publié et aucun dépôt n’a été modifié. Toute publication nécessite une nouvelle validation.

## Contenu et provenance

Adaptation des 24 pages du PDF fourni « Recevoir une FIS dans votre station » et « Comment tester le Live FIS », signé A.D. 2025. Les formulations ont été raccourcies et regroupées en huit rubriques. Les délais et procédures reprennent cette édition, sans mise à jour réglementaire. Les liens sont ceux du document ; WebFFS utilise l’adresse `inscription.ffs.fr` citée page 4.

48 captures originales sont restituées en WebP avec les flèches et repères du PDF, accompagnées du logo FFS extrait du même document. Les logos répétés ne sont pas conservés. Les cadrages conservent les flèches et les indications associées du PDF. Le PDF original est également inclus. Les légendes indiquent la page source. Le guide distingue l’envoi XML des résultats et celui du Timing Report.

## Utilisation

- Le sommaire ouvre la rubrique sélectionnée ; chaque rubrique possède une adresse avec ancre.
- Les captures sont visibles directement après les étapes correspondantes et s’agrandissent au clic. Échap ferme la fenêtre ; le focus revient au lien.
- Les boutons permettent de tout déplier ou replier. L’impression ouvre toutes les rubriques et conserve les captures intercalées.
- Sans JavaScript, les rubriques et galeries restent dépliables et chaque image s’ouvre directement.
- Mise en page adaptée aux écrans mobiles, navigation au clavier et réduction des animations selon les préférences du navigateur.
